## 👋 About

I spend most of my time on **backend systems, databases, servers, and infrastructure**.

I like following a system from end to end — from the API, through the database, container, reverse proxy, network, and storage, down to the server it runs on. When something breaks, I want to understand the whole path, not just one layer.

Building something is only part of the job. **Keeping it running is where things get interesting** — backups, monitoring, logs, replication, migrations, and what happens when something eventually fails.

I write down what I learn at **[ilham.dev](https://ilham.dev)**.
